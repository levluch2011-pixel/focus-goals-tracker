# 🎯 Напоминатель и Трекер Целей (Goal Reminder & Tracker)

Современное настольное приложение для Windows для постановки целей, контроля дедлайнов и анализа эффективности.

---

## 🌟 Основные возможности

### 1. ⏰ Постановка целей и гибкие сроки (Дедлайны)
- Создание цели с названием, подробным описанием и категорией (*Работа, Учеба, Спорт, Личное и др.*).
- **Быстрые кнопки установки срока**:
  - `⚡ Сегодня (до 23:59)`
  - `⏳ 1 день`
  - `📅 3 дня`
  - `🗓️ 1 неделя`
  - `🗓️ 2 недели`
  - `🌙 1 месяц`
- Возможность задать точную дату и время дедлайна вручную.
- Живой обратный отсчёт времени до дедлайна прямо на карточке цели (*например: «Осталось: 2 дн. 4 ч.»*).

### 2. 🗂️ Сортировка и фильтрация по срокам
Быстрое переключение категорий срочности в боковой панели:
- **⚡ Остался 1 день** — горящие цели, до окончания которых осталось менее 24 часов.
- **⏳ На 3 дня** — цели с дедлайном в пределах 3 суток.
- **📅 На неделю** — цели на ближайшие 7 дней.
- **🗓️ На 2 недели** — цели на 14 дней.
- **🌙 На месяц** — среднесрочные цели до 30 дней.
- **📌 Все активные** — полный список текущих задач.

### 3. ❌ Учёт провальных и выполненных целей
- **Автоматический переход в «Проваленные»**: если дедлайн наступил, а цель не была закрыта, приложение автоматически помечает её как проваленную и отправляет уведомление.
- **Ручное управление**: цель можно вручную отметить как выполненную (`✅ Выполнить`) или проваленную (`❌ Провалена`).
- **Шанс на исправление**: любую проваленную цель можно **продлить или возобновить** с новым сроком (`🔄 Продлить / Вернуть`).
- **Анализ эффективности**: верхняя панель статистики отображает процент выполненных и проваленных целей.

### 4. 🔔 Всплывающие уведомления Windows (Toast Notifications)
- Оповещение при наступлении дедлайна и автоматическом переводе в проваленные.
- Предупреждение за 24 часа до окончания срока.
- Поздравление при успешном выполнении цели.

### 5. 🎨 Удобный интерфейс
- Современный дизайн на **CustomTkinter** с поддержкой тёмной и светлой темы.
- Мгновенный поиск по названию или описанию.
- Сортировка карточек (по ближайшим срокам, по алфавиту, по дате добавления).

## 🚀 Как запустить приложение

### Вариант 1 (Самый простой — в 1 клик):
Просто запустите файл **`run.bat`** двойным щелчком мыши.

### Вариант 2 (Через терминал):
1. Установите зависимости (если ещё не установлены):
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   python main.py
   ```

## 📁 Структура проекта
- `main.py` — Точка входа в программу.
- `app.py` — Главное графическое окно со списком карточек, фильтрами и статистикой.
- `dialogs.py` — Модальное окно создания и редактирования целей с пресетами сроков.
- `database.py` — Хранилище SQLite (`goals.db`), логика фильтров и автопроверки просроченных задач.
- `notifier.py` — Модуль отправки нативных всплывающих уведомлений Windows (`winotify`).
- `run.bat` — Скрипт быстрого запуска для Windows.
